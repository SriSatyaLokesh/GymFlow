# Phase 12 Plan 01: Implement PBL Gamification (Points, Badges, Leaderboard, PRs)

## Objective

Introduce a gamification layer (PBL) to GymFlow to drive member retention and workout logging consistency. All member points, unlocked badges, and PRs will sync directly to the member document for sub-second page loads. We will use a dedicated `badges` Firestore collection to store badge definitions. Streaks will be calculated with rest-day grace (Sundays/rest days). Leaderboards will be rendered as a tabbed component on the Dashboard. Unlocks will display an interactive modal with a confetti burst.

---

## Proposed Database & Rule Schema Changes

### 1. Register `badges` Collection
In `lib/firebase-init.js`, `app.js`, and `modules/utils.js`, register `badges` (plural `badges` in Firestore).

### 2. Seed Default Badges (local & seed.html)
Add default badges to the DB on startup or seed:
- `streak-starter`: "Streak Starter" (3-day streak), streak type, threshold 3, icon: `local_fire_department`
- `unstoppable`: "Unstoppable" (7-day streak), streak type, threshold 7, icon: `whatshot`
- `consistency-50`: "Consistency King" (50 workouts completed), count type, threshold 50, icon: `military_tech`
- `consistency-100`: "Iron Addict" (100 workouts completed), count type, threshold 100, icon: `workspace_premium`
- `consistency-250`: "Century Club" (250 workouts completed), count type, threshold 250, icon: `stars`
- `pr-hitter`: "Limit Breaker" (First PR hit), PR type, threshold 1, icon: `fitness_center`
- `heavy-lifter`: "Heavy Lifter" (Lifted set >= 100kg/220lbs), weight type, threshold 100, icon: `sports_gymnastics`

### 3. Firestore Rules (`firestore.rules`)
```javascript
match /badges/{badgeId} {
  allow read: if signedIn() && sameGym();
  allow write: if signedIn() && sameGym() && owner();
}

match /members/{memberId} {
  allow read: if signedIn() && sameGym();
  allow update: if signedIn() && request.auth.uid == resource.data.uid && sameGym() && incomingSameGym();
}
```

## Tasks

### Task 1: Data Infrastructure & Seeding
- Register the `badges` collection in `lib/firebase-init.js`, `app.js`, and `modules/utils.js`.
- Add local storage seeding of default badges in `createLocalServices` inside `lib/firebase-init.js`.
- Add Firebase seeding of default badges in `seed.html`.
- Add the new Firestore rules to `firestore.rules`.

### Task 2: Points, Streaks & PR Evaluation Logic
- In `modules/utils.js`, add helper functions:
  - `calculateStreak(attendanceRecords)`: returns current streak count taking Sunday/declared rest-day grace into account.
  - `awardPointsAndBadges(context, actionType, details)`: evaluates point additions (10 for check-in, 50 for workout, 100 for PR), checks daily anti-abuse caps (max 1 check-in, 2 workouts daily), checks if milestones/streaks unlock any badges, updates `members` document, and opens the celebration modal if unlocked.
- In `modules/attendance.js`:
  - When self check-in triggers, call `awardPointsAndBadges(context, 'checkin')`.
- In `modules/my-workout.js`:
  - When finishing a workout log, check each set's weight against the member's `members.personalRecords` dictionary.
  - If weight exceeds current PR (or if exercise is new), record PR, award points, and evaluate PR badges.
  - Evaluate total workout counts and trigger badge checks. Call `awardPointsAndBadges(context, 'workout', { prsHit, totalWorkouts })`.

### Task 3: Tabbed Leaderboard Panel
- In `modules/dashboard.js`, implement `renderLeaderboards(context)` and display it at the bottom.
- Query and filter members of the same `gymId` where `privateLeaderboard != true`.
- Compute consistency streaks for all matched members in-memory.
- Predefine weight classes: Under 65kg, 65-75kg, 75-85kg, 85kg+.
- Render tabs:
  - **Points**: Ranked by total points descending.
  - **Consistency**: Ranked by current streak count descending, with monthly check-in count as tie-breaker.
  - **Weight Class**: Points ranking filtered by member's gender and matching weight range.
- Bind click events for tab toggles in the `bind` method.

### Task 4: Profile Integration & Confetti Modal
- Include the `canvas-confetti` script inside `index.html` header via CDN.
- In `modules/progress.js`, add a "Badges & PRs" tab displaying:
  - Unlocked badges (colored) and locked badges (grayed out) with icons & descriptions loaded from the `badges` collection.
  - Personal Records table (exercise name and max weight).
- In `modules/members.js`:
  - Profile edit form: add a checkbox for `privateLeaderboard` ("Hide me from leaderboards").
  - Member Details view: add an "Achievements" tab rendering points, unlocked badges, and PR list (read-only).
- Implement `showCelebrationModal(type, title, description, icon)` inside `modules/utils.js` displaying a modal and launching confetti particle bursts via `confetti()`.
