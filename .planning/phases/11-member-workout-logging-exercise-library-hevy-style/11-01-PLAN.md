# Phase 11 Plan 01: Trainer & Owner Read UI for Member Workout Logs, Schedules, and Custom Routines

## Objective

Currently, members can log workouts, save custom routines, and set up a weekly workout schedule in the "My Workout" portal. While the completed workout logs are visible to trainers/owners under the member details profile modal (`showMemberProfileModal` in `modules/utils.js`), the member's active weekly schedule and custom routines are not visible.

This plan integrates the member's weekly schedule (Monday-Sunday routine mapping) and custom routines list directly into the "Workout Logs" tab of the member profile details modal, providing trainers and gym owners with complete visibility into the member's current workout planning and history.

## Current Problem

- `showMemberProfileModal` in `modules/utils.js` fetches and filters `workout_logs` for the member.
- It does not load or display `workout_schedules` (which contains both type "routine" and type "schedule" documents for the member).
- Gym owners and trainers cannot verify what routines a member is scheduled to perform.

## Proposed UI/UX Changes

In `modules/utils.js`, update `showMemberProfileModal(member, context)`:

1. Retrieve all `workout_schedules` records for the target member:
   ```js
   const mySchedules = (context.data.workout_schedules || []).filter(s => s.memberId === member.id);
   const customRoutines = mySchedules.filter(s => s.type === "routine");
   const weeklyScheduleDoc = mySchedules.find(s => s.type === "schedule") || { schedule: {} };
   ```
2. In the "Workout Logs" tab template, add a two-column grid (or stack) at the top:
   - **Weekly Schedule**: A read-only layout displaying Monday-Sunday and the assigned routine/template name (or "Rest Day").
   - **Custom Routines**: A list of the member's custom routines showing the exercises and target sets/reps.
3. Keep the completed "Workout Logs" list beneath this new section under a heading: **Completed Workout Logs**.

## Tasks
